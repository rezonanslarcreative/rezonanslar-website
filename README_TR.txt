GITHUB DESKTOP İLE YAYINLAMA
1. GitHub Desktop > File > New repository
2. Name: rezonanslar
3. Local path olarak bu klasörü seç veya önce boş repo oluşturup bu dosyaları içine kopyala.
4. Commit summary: Initial REZONANSLAR website
5. Commit to main
6. Publish repository
7. GitHub web > repository > Settings > Pages
8. Build and deployment: Deploy from a branch
9. Branch: main / (root) > Save
10. Birkaç dakika sonra site adresi oluşur.
